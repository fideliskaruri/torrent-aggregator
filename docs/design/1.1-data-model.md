# 1.1 Data model

Phase 1, OPS-658 / FEAT-35. This is the final logical schema, not an EF implementation.
See [interfaces](1.3-interfaces.md) for write boundaries and [migration](1.6-migration.md)
for the exact old columns. Store executes writes; the owner below authorizes their meaning.

## Conventions and final list

SQLite, one database, WAL, `foreign_keys=ON`, busy timeout 5 s. IDs are immutable TEXT
(preserve old IDs; new IDs UUID v7 strings). C# `string`, `int`, `long`, `double`, `bool`,
`DateTimeOffset` map to TEXT, INTEGER, INTEGER, REAL, INTEGER CHECK(0/1), UTC ISO-8601 TEXT.
Enums are lower-case TEXT with CHECK constraints. `?` means NULL allowed; everything else
is NOT NULL. `json<T>` is TEXT with `json_valid`, schema version checked on read/write.
Dates of unknown precision retain a precision field: a day is not invented midnight UTC.
Every `id` is a primary key unless a composite PK is given. All FK deletions RESTRICT
unless stated otherwise. `U` = unique index; `I` = ordinary index. Every table's indexes
below are in addition to its PK. Numeric sizes/counts nonnegative; rank is signed Int64.
Rows with `version` use application-maintained Int64 CAS, not SQLite rowversion.

**35 application tables**, plus Store's own EF migration history/lock:

| Group | Tables | Reconciliation with plan |
|---|---|---|
| Catalog | Work, WorkName, WorkLink, Season, Episode, MetadataCache | WorkName/WorkLink normalize names and provider identity; MetadataCache replaces catalog/provider/Fribb JSON caches, not ownership |
| Intent | WorkPreference, Target, ScopeIntent, RawIntent, Request, RequestItem, AutoApproveRule, Follow, WatchItem, AutoRule | ScopeIntent owns unresolved owner scope; RawIntent owns target-less transfers; RequestItem separates individual obligations |
| Discovery | Release, ReleaseObservation, Verdict, UpgradeEvidence, Attempt, Block, SearchCache | Observations preserve source provenance; UpgradeEvidence is expiring per-item knowledge, not watch state |
| Engine | Download, DownloadTarget, DownloadFile | Associations are necessary for packs and temporary replacement overlap; no copied progress |
| Files | StorageRoot, WorkFolder, MediaFile, FileOperation, FilePathClaim | Pin item folders and serialize exact-path operations; no side journals/tombstones |
| People/system | User, Notification, PushSubscription, Setting | Secrets referenced, not copied into Setting |

The plan's storage appendix enumerates 19 tables including Season/Episode and the two
library tables; the additions above reconcile requests, follows, identities, relations
and crash-safe file operations rather than creating alternative state stores.

## Catalog

### Work (Metadata)

| Field | Type | Meaning |
|---|---|---|
| id; workKey | string; string | PK; immutable public key, existing URLs preserved |
| kind; format; anime | Film/Series/Unknown; Movie/Series/Special/Unknown; bool? | Provider facts; unknown never guessed from a torrent; Unknown shells can retain waiting intent but cannot admit catalog payload |
| year; originalLanguage; runtimeMinutes | int?; string?; int? | Provider facts |
| posterUrl; backdropUrl; synopsis; rating; ratingSource | string?; string?; string?; double?; string? | Shared display facts, rating 0..10 |
| genresJson | json<string[]> | Empty array allowed |
| theatricalAt; digitalAt; physicalAt; releasePrecision | time?; time?; time?; Unknown/Day/Instant | Films' availability/calendar evidence |
| providerStatus; numberingVersion | string?; string? | Returning/finished etc.; confirmed mapping version |
| refreshedAt; createdAt; updatedAt; version | time?; time; time; long | Weekly cache refresh; CAS |

U(workKey); I(kind,anime); I(digitalAt); I(refreshedAt).
There is **no canonicalTitle or ids JSON**: display title is the first ordered English
WorkName, otherwise Original/Romaji/Synonym/Native; external IDs come from WorkLink.
Work rows referenced by intent/files cannot be evicted just because their cache expired.

### WorkName (Metadata)

id string; workId FK Work; value string; normalizedValue string; label
English/Romaji/Synonym/Native/Original; linkId FK WorkLink?; ordinal int;
authoritative bool; refreshedAt time?.
U(workId,normalizedValue,label,linkId) uses `coalesce(linkId,'')` expression to make
NULL uniqueness real; I(workId,ordinal). Normalization is Unicode/punctuation and
case insensitive; blanks refused. Same name with different provenance is permitted.
Removing a link removes only its own names (link FK CASCADE); obsolete authoritative
labels become synonyms unless another current provider supplies that label.

### WorkLink (Metadata)

id string; workId FK Work; provider string; externalId string; providerKind string?;
seasonId FK Season?; source string; mappingVersion string?; confidence double;
status Verified/Suggested/Rejected; isPrimary bool; createdAt time; updatedAt time.
U(workId,provider,externalId,coalesce(providerKind,'')); U(provider,externalId,providerKind)
**WHERE status='verified'** (expression coalesces null); U(workId) WHERE isPrimary=1.
I(workId,status). A rejected link persists; refresh cannot resurrect it. A series may
link multiple AniList entries scoped to Season. Never merge works by title alone.

### Season (Metadata)

id string; workId FK Work; number int; title string?; overview string?; posterUrl string?;
mappingStatus Confirmed/Provisional/Unavailable; providerEntryId string?;
expectedEpisodeCount int?; refreshedAt time?; createdAt time; updatedAt time; version long.
U(workId,number); I(mappingStatus,refreshedAt). Count is provider-reported expected total,
not the derived downloaded/aired count. Season 0 supports specials.

### Episode (Metadata)

id string; seasonId FK Season; number int; absoluteNumber int?; provider string?;
providerEpisodeId string?; title string?; synopsis string?; stillUrl string?;
airAt time?; airPrecision Unknown/Day/Instant; runtimeMinutes int?;
mappingStatus Confirmed/Provisional/Unavailable; createdAt time; updatedAt time; version long.
U(seasonId,number); U(provider,providerEpisodeId) WHERE providerEpisodeId IS NOT NULL;
I(airAt); I(seasonId,absoluteNumber). Episode ID is stable through renumbering.
Coordinate changes update Season/Episode only, not strings in targets or requests.
Map revisions are deferred while active selection relies on the old map; collisions
require reviewed evidence, not guessed sequel coordinates.

### MetadataCache (Metadata)

id string; kind ProviderDetail/TitleSearch/BrowseRail/FribbMap/JellyfinState;
cacheKey string; payloadJson json<versioned cache payload>; fetchedAt time;
expiresAt time; etag string?; lastModified string?; complete bool; provider string?.
U(kind,cacheKey); I(expiresAt). Browse rail payload contains **ordered Work IDs and rail
configuration**, not duplicate titles/posters. Daily refresh keeps last-good rail and
sticky provider on failure; serving a failed refresh marks stale. Fribb payload is the
last-good source map; WorkLink contains adopted/rejected claims. Jellyfin watch facts
are a read-through cache only, keyed by server/user/item, not TorrentFlow watch events.

## Intent

### WorkPreference (Targets)

id string; workId FK Work; resolutionFloor int?; preferredResolution int?;
audioLanguage string?; maxBytesPerItem long?; storageRootOverrideId FK StorageRoot?;
updatedAt time; version long. U(workId). Unknown audio is acceptable even with English
preference; only clear incompatible markers reject. Call-specific quality is recorded
on Target; this row is the owner's default for later actions, not live progress.

### Target (Targets, sole state authority)

| Field | Type | Meaning |
|---|---|---|
| id; workId; episodeId | string; FK Work; FK Episode? | One film (NULL episode) or one stable episode |
| kind | Acquire/Replace | Replace permits an owned item to acquire another file |
| state; resumeState | wanted/finding/checking/planning/fetching/filing/done/waiting/paused/removed; same enum? | No failed terminal state; resume hint only in paused/waiting |
| reasonCode; reasonText; nextTryAt | WaitReason?; string?; time? | Durable, honest waiting/error reason |
| expectedAt | time? | Intent's scheduling date, updated from metadata evidence |
| resolutionFloor; preferredResolution; audioLanguage; maxBytes | int?; int?; string?; long? | Effective accepted intent, not copied defaults |
| ownerRanked; rank; nowAt | bool; long; time? | Owner inputs only; effective priority computed at sort time from requests/follows/dates/current time |
| createdBy; origin; autoRuleId | FK User; Owner/Request/Rule/Follow/Upgrade; FK AutoRule? | Provenance, not separate states |
| chosenReleaseHash | FK Release? | Committed choice, including token-bound Upgrade or cap-deferred plan; never a speculative memo |
| replaceMediaFileId | FK MediaFile? | Old file preserved until replacement is filed |
| replacementMode | Upgrade/Replace? | Required for kind Replace; Upgrade strictly improves best owned resolution, Replace meets or exceeds it |
| batchId; clickedAt | string?; time? | One accepted action's summary; explicit film/episode click |
| substantiveMisses; helpNotifiedAt | int; time? | Busy/unknown metadata never increments misses |
| policyRevision; leaseUntil; leaseToken | long; time?; string? | Cancel stale work and recover one worker's claims |
| createdAt; updatedAt; version | time; time; long | CAS |

U(workId) WHERE episodeId IS NULL; U(episodeId) WHERE episodeId IS NOT NULL;
I(state,nextTryAt,rank); I(batchId); I(chosenReleaseHash).
Cross-row guard: episode belongs to work; a film has no episode. Removed/done rows remain
the same identity when explicitly reactivated; version/policyRevision fence old callbacks.
`chosenReleaseHash` is also permitted on a cap-deferred planned target without Download;
it supplies the Queued API projection, not an active engine claim. Admission/swap changes
chosenReleaseHash and Current association in the same commit; fetching always has Current.
Requests are many-to-one: do not create a Target per requester.

### ScopeIntent (Targets)

id string; actorUserId FK User; workId FK Work; scope Film/Episodes/Seasons/Series;
scopeJson json<RequestScopeData>; policyJson json<Policy>; now bool; batchId string;
state Pending/Materialized/Cancelled; nextTryAt time?; createdAt time; updatedAt time;
version long. I(state,nextTryAt); I(workId); I(batchId).
Accepted unresolved owner scopes live here, never in Attempt. Materialization atomically
creates stable Targets/links and marks Materialized; repeat receipt/batch cannot expand twice.
Pending intent survives history expiry. Owner cancellation fences pending expansion.

### RawIntent (Targets; state holder for target-less Download)

id string; actorUserId FK User; releaseHash FK Release; downloadId FK Download?;
selectedFilesJson json<int[]>; rootId FK StorageRoot?; explicitDirectory string?;
explicitKind LibraryKind?; state Wanted/Checking/Planning/Fetching/Filing/Review/Done/
Waiting/Paused/Removed; resumeState same enum?; reasonCode WaitReason?; reasonText string?;
nextTryAt time?; nowAt time?; ownerRanked bool; rank long; leaseUntil time?;
leaseToken string?; batchId string; createdAt time; updatedAt time; version long.
U(downloadId) WHERE downloadId IS NOT NULL; I(state,nextTryAt); I(releaseHash).
Explicit raw owner intent uses the same budgets/gates/Run-Stop admission, not a fake
catalog Target. Safe completion publishes files only in the explicit destination and
enters Review with Library import proposals; MediaFile requires confirmed work identity.
No catalog ownership before reviewed adoption. State/paths survive restart.

### Request (Targets)

id string; userId FK User; workId FK Work; scope Film/Episodes/Seasons/Series;
scopeJson json<{seasons:int[],futureEpisodes:bool}>; note string?;
decision Pending/Approved/Declined/Cancelled; decisionReason string?;
decidedAt time?; decidedBy FK User?; createdAt time; updatedAt time; version long.
I(userId,decision,createdAt); I(workId,decision).
Public `status` (pending/approved/downloading/partial/fulfilled/failed) is **derived**
from decision and RequestItems, not stored as a competing lifecycle.
Group ask by work+normalized scope, not by a copied aggregate status.

### RequestItem (Targets)

id string; requestId FK Request CASCADE; episodeId FK Episode?; targetId FK Target?;
settlement Open/Fulfilled/StoppedByOwner; settledAt time?; createdAt time; updatedAt time.
U(requestId,coalesce(episodeId,'')); I(targetId); I(requestId,settlement).
Work is the Request's work. NULL episode is film. Historical fulfilment is irreversible
without an explicit retry; physical deletion does not silently reopen history.
Future season episodes add new items only above saved settlements. Target reference is
NULL for owned-at-submit fulfilment; no fake download row is needed.

### AutoApproveRule (Targets)

id string; normalizedEmail string; mode None/MoviesOnly/Everything;
createdAt time; updatedAt time; version long. U(normalizedEmail).
Global mode lives in Setting.requests once; per-email override here. At most 200 rules;
normalized email length <=320. Same approve command for manual and automatic decisions.

### Follow (Targets)

id string; workId FK Work; enabled bool; fromEpisodeId FK Episode?;
newEpisodesSince time; lastMaterializedAt time?; createdAt time; updatedAt time; version long.
U(workId); I(enabled,lastMaterializedAt). Follow is owner's auto-want flag. Save without
an explicit start -> first airing after newEpisodesSince, never S01E01 fallback.
Effective quality comes from WorkPreference. Unknown airing/mapping postpones the cursor.

### WatchItem (Targets)

id string; userId FK User; workId FK Work; status Watching/Planned/Completed/Dropped;
upgradeWatch bool; createdAt time; updatedAt time; version long.
U(userId,workId); I(upgradeWatch). This is the saved catalog/UI list.
Legacy `monitored` maps to Follow.enabled, not duplicated here. Upgrade watch notifies,
never creates Replace targets by itself. Per-item evidence is in UpgradeEvidence.

### UpgradeEvidence (Targets)

id string; workId FK Work; episodeId FK Episode?; candidateHash FK Release?;
resolution int?; checkedAt time; expiresAt time.
U(workId,coalesce(episodeId,'')); I(expiresAt).
Exists for owned films/episodes whether watched or not; NULL candidate records a completed
check with no healthy upgrade. Best Good/Weak gate-passing candidate only, expiry <= its
Verdict expiry and default 6 h. API derives best-available/check-age and upgrade counts
per item; expired evidence cannot enable Upgrade. A choice token revalidates evidence,
ownership and Target version at acceptance/admission.

### AutoRule (Targets)

id string; userId FK User; name string; query string; category string;
minListedSeeders int; maxBytes long?; resolutionFloor int?; sourceIdsJson json<string[]>;
enabled bool; lastRunAt time?; lastMatchHash FK Release?; matchCount int;
createdAt time; updatedAt time; version long. I(userId,enabled,lastRunAt).
Seeds are an explicit owner's rule prefilter, never evidence replacing Check.
Matched episode releases resolve catalog identity and then use ordinary Targets.

## Release knowledge

### Release (Find; Library may append verified file metadata through Targets)

hash string PK, normalized 40-hex v1 or 64-hex v2; name string; parsedJson
json<ParsedRelease>; totalBytes long?; torrentUri string?; magnet string?;
filesJson json<TorrentFile[]>?; metadataDigest string?; private bool?;
firstSeenAt time; lastSeenAt time. I(lastSeenAt).
File list is hash-bound immutable torrent metadata, not a duplicate in Verdict.
Keep 30 days unless referenced; unknown sizes are NULL, not zero. Invalid hashes never
participate in admission; display-only invalid source rows remain in diagnostics.

### ReleaseObservation (Find)

id string; hash FK Release CASCADE; sourceId string; sourceItemId string?; query string;
listedSeeders int?; listedLeechers int?; uploadedAt time?; observedAt time;
torrentUri string?; webSeedsJson json<string[]>.
U(hash,sourceId,query); I(sourceId,observedAt).
Conservative listed count = lowest nonnegative **reported** count across current
observations; absent is not 0. Check's answered scrape supersedes listed evidence, but a
zero scrape never alone proves dead. SourceItemId survives dedupe (ApiBay etc.).

### Verdict (Targets commits Check's returned evidence)

hash FK Release PK; band Good/Weak/Dead/Unknown; connectedPeers int;
connectedSeeders int; byteSendingPeers int; bytesDelivered long; sampleMilliseconds int; scrapedSeeders int?;
reason string; checkedAt time; expiresAt time; probeVersion int.
I(expiresAt); I(checkedAt). File list lives in Release. Verdict expires in 6 h; expiry,
invalid version or missing row reads Unknown. Unknown for wanted targets expires in 45 min;
other bands/default speculative Unknown expire in 6 h. Fresh Unknown is not reprobed in a
speculative sweep. Cancelled probes and live transfer snapshots never populate this table.

### Attempt (Targets)

id string; targetId FK Target?; workId FK Work?; releaseHash FK Release?;
actorUserId FK User?; kind Search/Check/Plan/Fetch/File/Swap/LegacyEvent;
startedAt time; endedAt time?; outcome string?; reasonCode string?; reasonText string?;
decisionJson json<{policyRevision,rejections,selectedFiles,sourceErrors}>?;
legacyContextJson json<object>?; batchId string?; downloadId FK Download?;
deadlineAt time?; swapJson json<SwapDecision>?.
I(targetId,startedAt); I(workId,startedAt); I(actorUserId,startedAt); I(releaseHash).
History is immutable; close an open attempt once. Plan reasons kept 30 days, then clear
decisionJson, not the event. Older history with no recoverable target remains targetId=NULL.
No live progress copied here. Reasons are historical decisions, not duplicate current state.
U(downloadId) WHERE kind='swap' AND endedAt IS NULL; I(kind,endedAt,deadlineAt).
Swap has a 20 min deadline and captures all affected target IDs, old/replacement Download
IDs (a Plan may choose several replacement hashes), old completed bytes/per-target baselines
at switch and sustained-Good start. These are decision evidence,
not live progress. Old bytes remain protected until replacement completes or exceeds this
baseline at sustained Good rate. The 20 min deadline governs pre-switch replacement proof,
not post-switch fallback retention; close failed/cancelled Attempt at abort, successful
Attempt after retained-partial cleanup. Open swap evidence may be filled at proof/cleanup
boundaries but is frozen after close, never used as a search work queue.
An open Swap Attempt is durable coordination, not pending owner scope.

### Block (Targets, safety conclusions from Plan/Library)

id string; hash string (no FK, outlives release); workKey string? (no FK);
reason string; origin Owner/Unsafe/Foreign/Stalled/Swap; replacedByHash string?;
createdAt time; until time?. U(hash,coalesce(workKey,'')); I(until); I(workKey).
NULL workKey means global. Proven danger gets global block; performance/swap is scoped.
Owner Use anyway may override a scoped preference block, **never safety/identity/floor**.

### SearchCache (Find)

id string; normalizedQuery string; scopeKey string; sourceId string;
sourceRevision long; credentialRevision long; parserVersion int;
payloadJson json<{releaseHashes:string[],sourceResult}>; complete bool;
createdAt time; expiresAt time.
U(normalizedQuery,scopeKey,sourceId,sourceRevision,credentialRevision,parserVersion);
I(normalizedQuery,expiresAt); I(expiresAt).
30 min, successful complete source responses only. Empty successful responses cache;
partial/error/cooldown do not become negative cache. Ordered query pool resolves hashes
to Release/Observation, not duplicate current counts.

## Engine relations

### Download (Targets owns durable intent; Engine owns resume artifacts, not this state)

id string; hash FK Release; intent Run/Queued/Paused/Stopped; rootId FK StorageRoot?;
addedAt time; finishedAt time?; admissionToken string; resumeArtifact string?;
rawIntentId FK RawIntent?; version long. U(hash); U(admissionToken); I(intent,addedAt).
No target coordinate, quality, source, fraction, rate, peers or queue rank columns.
Resume artifact points inside the new engine data directory; hash bitfield/DHT are
engine-private binary artifacts, never a second application truth. One manager per hash.
Completion is observed live and recorded as a lifecycle timestamp, not copied progress.
rawIntentId links a target-less transfer; never mixed with DownloadTarget.
`intent` is Targets' sole admission-decision cache, committed atomically with related
Target/RawIntent transitions. It is recomputed from eligible associations on recovery.
Engine receives only Run/Stop, not cap/window/ranking inputs. Retired associations never
participate in admission; no Target copying of Download state or progress.

### DownloadTarget (Targets)

id string; downloadId FK Download; targetId FK Target; role Current/Replacement/Retired;
createdAt time. U(downloadId,targetId);
U(targetId) WHERE role='current'; U(targetId) WHERE role='replacement';
I(downloadId,role). No array of target IDs on Download. A pack shares one Download among
many targets. Only the temporary replacement may overlap a current transfer.
Re-admission of a retired (downloadId,targetId) updates that row to Current, never inserts
a duplicate. Completion/failure/removal retire links in the same commit as state changes.
Detached resumable cap/window/owner pauses also retire Current; resume reactivates it
atomically before Run. Other active pack targets retain their own Current associations.

### DownloadFile (Targets: selected; Library: paths; Store commits jointly)

id string; downloadId FK Download; fileIndex int; selected bool;
targetId FK Target?; partialPath string?; finalPath string?; physicalKey string?;
mediaFileId FK MediaFile?; role Video/Subtitle/Audio/Unwanted; expectedBytes long;
enginePath string?; filed bool.
U(downloadId,fileIndex); U(physicalKey) WHERE physicalKey IS NOT NULL;
I(targetId); I(mediaFileId).
Torrent-relative name/length also available in Release.filesJson; expectedBytes is the
allocation contract at admission. Path fields are reservations while fetching; upon
filing, MediaFile owns the actual path and reservation path fields become NULL in one commit.
enginePath retains the rebound final path and filed=true; selected=false for filed files.
This is an engine binding, not a second inventory; it must equal the linked MediaFile.path.
Recovery includes filed final bindings (DoNotDownload) so a pack can hash-check boundaries
without recreating partials or re-downloading filed episodes.
Skipped boundary fragments have no MediaFile, live only under .unwanted.
Selection updates are durable BEFORE changing engine priorities.
Store requires every nonnull DownloadFile.targetId to have a matching DownloadTarget for
the same download (including Retired for filed/history/resumable suspended files).
Selected+RUNNING payload claims require Current/Replacement; Retired+selected may preserve
durable resume selection but must be excluded from active Engine bindings. Work/episode/
file mapping must agree in that joint commit.

## Files

### StorageRoot (Library, settings changes requested through Targets)

id string; path string; physicalKey string; kindsJson json<LibraryKind[]>;
libraryFoldersJson json<{Movies,TV,Anime,AnimeMovies:string}>;
volumeSerial string; priority int; reserveBytes long; maxAllocatedBytes long?; enabled bool;
online bool; reviewRequired bool; lastCheckedAt time?; lastError string?;
createdAt time; updatedAt time; version long.
U(physicalKey); I(enabled,priority).
Path rule overrides map here, not a duplicated Setting path rule. `Anime` is a logical
kind; **existing physical `Anime Series` remains unchanged**, see 1.5.
Root deletion is refused while any media/download/operation references it; disabling is
allowed. Online is a sampled fact, no stored free-space count; incomplete scan != missing.
Online requires `.torrentflow-root` containing this immutable id AND matching volumeSerial/
physicalKey. Missing/mismatched identity is Offline, not an empty library. Root enrollment
creates the marker only on owner-confirmed correct volume, never during a failed scan.
EnrollRoot/ConfirmRoot are explicit owner LibraryCommands; confirmation token binds the
sampled root/volume/version and review evidence, not just an unvalidated path string.
Mass vanish >10% OR >20 previously inventoried files per root/scan marks root/files Offline,
sets reviewRequired=true, asks owner and suppresses Missing/pruning/reacquisition until
explicitly resolved. Later accessible scans never auto-clear this durable hold.

### WorkFolder (Library proposes; Targets commits)

id string; workId FK Work; rootId FK StorageRoot?; relativeItemFolder string?;
externalItemFolder string?;
createdAt time; updatedAt time; version long.
U(workId); U(rootId,relativeItemFolder) WHERE rootId IS NOT NULL;
U(externalItemFolder) WHERE externalItemFolder IS NOT NULL.
Pins root AND item folder per work; path is root-relative, beneath its configured kind
folder, excluding season suffix. Migration records actual existing folder; conflicts
across roots require reviewed choice. New placement creates the pin atomically with path
claims. English display/search name refresh never renames it. Explicit MoveTitle/rename
updates pin and inventory through verified operations, no implicit title tidy.
Exactly one shape: managed rootId+relativeItemFolder and NULL externalItemFolder, or
NULL rootId/relativeItemFolder with absolute externalItemFolder for track-in-place work.
An external pin does not authorize payload writes; additional episodes wait for explicit
owner enrollment/placement/move, never silently create a second English-named series folder.

### MediaFile (Library, the sole ownership inventory)

id string; workId FK Work; episodeId FK Episode?; rootId FK StorageRoot?;
path string; physicalKey string; role Video/Subtitle/Audio; parentMediaFileId FK MediaFile?;
bytes long; mtimeUtc time; resolution int?; source string?; container string?;
videoCodec string?; videoProfile string?; width int?; height int?; hdr string?;
runtimeSeconds double?; bitrateBps long?; tracksJson json<MediaTrack[]>;
origin Downloaded/Imported/Adopted; downloadId FK Download?; fileIndex int?;
addedAt time; lastSeenAt time?; missingSince time?; status Present/Offline/Missing;
missingConfirmedAt time?;
verifiedAt time?; contentDigest string?; version long.
U(physicalKey); U(downloadId,fileIndex) WHERE downloadId IS NOT NULL;
I(workId,episodeId,status); I(rootId,status); I(parentMediaFileId); I(missingSince).
rootId NULL is track-in-place outside managed roots; an inaccessible external path is
Offline/unknown, not Missing. Owned = at least one validated VIDEO Present or Offline
for the item; unconfirmed Missing is protected from reacquisition as if owned. Sidecars alone are not ownership. Duplicate videos per item are allowed
and shown for review, never silently overwritten. Missing needs two complete identity-valid
scans at least 6 h apart; first sets missingSince, second sets missingConfirmedAt. No T29,
reacquisition or pruning before confirmation. Any reappearance resets both fields.
Confirmed Missing rows retained 30 days from confirmation; keep
Target/RequestItem settlements after pruning. Origin is INTERNAL and never on user DTOs.
Probe media once on addition using in-process readers, no ffmpeg/ffprobe; absent track
facts stay unknown and do not prevent download/ownership.

### FileOperation (Library)

id string; kind Rename/Move/Copy/Delete/Import/Relocate;
targetId FK Target?; downloadId FK Download?; mediaFileId FK MediaFile?;
sourcePath string?; destinationPath string?; expectedBytes long?;
expectedDigest string?; state Pending/Copied/Verified/InventoryCommitted/SourceDeleted/
Done/Retry/NeedsOwner/Superseded;
deleteSource bool; attempts int; nextTryAt time?; lastError string?;
createdAt time; updatedAt time; leaseToken string?; leaseUntil time?;
resumeStage FileOperationState?; enginePermitToken string?.
I(state,nextTryAt); I(downloadId); I(mediaFileId).
This stores operation INTENT, not another inventory. Store intent before touching disk,
then verify, update inventory, then delete exact source if explicitly authorized.
Pending operations protect affected paths from scan adoption/deletion and startup
resurrection. Done operations retained 30 days; cleanup tombstones until successful.
One MaintenanceWorker executor claims by CAS lease (60 s, heartbeat 15 s); startup and
filing enqueue/reconcile through that executor, never perform competing disk work.
Retry remembers stage; mismatch is NeedsOwner, never an infinite destructive retry.
Delete supersedes only a not-yet-executing Pending Rename atomically; an executing rename
must settle and transfer its path claims before exact Delete. Delete waits for engine
detach+write-drain confirmation (or per-file drain/unselect proof for an active pack).

### FilePathClaim (Targets commits Library's operation proposal)

id string; operationId FK FileOperation; physicalKey string; createdAt time.
U(physicalKey); I(operationId). One active claim covers each source/destination physical
path (dedupe same path). Claim lifecycle is atomic with operation enqueue/Done/Superseded;
NeedsOwner keeps claims. DownloadFile reservations and MediaFile ownership must be
checked too: an operation may use only its own authorized inventory/reservations.

## People and system

### User (Targets)

id string; normalizedEmail string?; name string?; image string?;
role Owner/Requester; createdAt time; updatedAt time.
U(normalizedEmail) WHERE normalizedEmail IS NOT NULL; U(role) WHERE role='owner'.
Ensure local owner exists before serving; remote JWT identity cannot select arbitrary IDs.

### Notification (Targets; delivery is best effort)

id string; userId FK User; kind string; title string; body string?; link string?;
dedupeKey string?; createdAt time; readAt time?; pushPending bool;
pushAttemptAt time?; pushAttempts int.
U(userId,dedupeKey) WHERE dedupeKey IS NOT NULL; I(userId,createdAt); I(pushPending,pushAttemptAt).
One batch summary updated in place without changing createdAt/readAt or repushing.
Titles <=200/body <=500; no filesystem paths or magnets in pushes.

### PushSubscription (Targets)

id string; userId FK User; endpoint string; p256dh string; auth string;
createdAt time. U(endpoint); I(userId). Maximum 10/user; endpoint transferred to latest
subscriber. Browser subscription credentials are required DB data; VAPID private key
is a protected file. HTTPS endpoint/redirect/SSRF checks before dispatch; 404/410 removes.

### Setting (Targets owns system settings; Metadata/Sources consume snapshots)

section string PK; schemaVersion int; valueJson json<typed section>;
revision long; updatedAt time.
No indexes beyond PK. Sections: engine, sources, metadata, remoteAccess, desktop, quality,
requests, scheduler, jellyfin, migration. Whitelisted typed shapes in 1.3; no arbitrary
key bag accepted from HTTP. Secret field values are protected-file references only.
Engine listen port is stored here before binding, including a discovered replacement.
Changes invalidate readers immediately after transaction publication. Library roots
are rows, not a second list in Setting.

## Values deliberately not stored

| Value | Source of truth / computation |
|---|---|
| Display title, IDs, poster for a route | ordered WorkName + verified WorkLink + Work.posterUrl |
| Owned / ready / downloaded / import origin label | Library video presence; no origin label at all |
| Progress, speed, ETA, peers, selected-byte percent | EngineSnapshot, exact DownloadFile selection; offline manager => no made-up metrics |
| Queue position / series and season totals | current Target rank/order and stable Episode IDs; aggregate every row, not rendered subset |
| Missing episode set / pack coverage | metadata Episode set minus owned and healthy current claims |
| Request public status / fulfilment counts | Request.decision + RequestItem settlements + shared Target states |
| Aired count / season finished / availability | provider dates/status/expected count; unknown is not finished |
| Live available/free/reserved drive bytes | OS physical allocations plus union of promised pieces minus already allocated bytes |
| Release effective seeders / measured rate | Observation conservative count, Verdict scrape, bytes/window |
| Jellyfin watched/in-progress/next-up | remote read-through MetadataCache, no TorrentFlow playback tracking |
| Pick ranking / cached best pick | pure Plan evaluated against current pool, verdicts, ownership, blocks and policy |

## Transaction and retention invariants

Acquire transaction checks owned again, inserts/reuses Target, links RequestItems, commits
notification intent. Admission checks Target version and still-missing ownership, creates
Download+DownloadTarget+DownloadFile path reservations and Attempt atomically before engine
start. Engine calls use admissionToken and are idempotent. Failure compensates only that
admission's rows; reused/manual transfers survive. Retirement of shared packs removes only
selected target files; detach only when no selected incomplete file remains. During
removal/swap, files of other live pack targets are protected even if another link retires.

Metadata/file effects commit through typed Store rows with CAS. No SQL in API, no EF entities
outside Store. Write transaction never spans network/filesystem await. A table-owner violation
is rejected by scoped Store capability and architecture checks. Expiry maintenance runs inside
the existing maintenance service, not another hosted service.
Library returns unsaved rows/proposals for ALL inventory/path/operation changes; Targets is
the sole committer of joint commits. Check likewise returns Verdict+Release enrichment;
Targets commits them. Exact capability exceptions are listed in 1.3; no bypass via owner enum.
